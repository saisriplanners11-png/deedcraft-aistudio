# Template replacement policy

The user requires these behaviors to survive every future template upload or replacement. A request to change the Word template alone does not authorize undoing them. Change a rule only when the user explicitly requests that rule to change.

- Printed deed dates always use **DD-MM-YYYY**. Keep stored dates in ISO format. Use the shared `deed-format.ts` formatter for execution dates, births, authority/title/supporting records, payments, entity recitals and configured date fields. Do not print partial or impossible dates.
- Use the entered consideration/declared document value for all total market-value and estimate bindings, including Gift. Do not substitute calculated basic-rate market value. The separate per-unit rate and on-screen duty calculations retain their own meanings. Gift remains without monetary consideration in its operative wording and consideration row.
- A selected landmark relation prints **near house No.** or **adjacent house No.**, followed by its separately supplied number, in both property descriptions and valuation statements/annexures. Apply the same behavior to Sale, Gift, GPA and AGPA and to each property's own values. Preserve the distinction between a landmark number and the subject property's bearing number.
- Preserve the Gift relationship recital, donor/donee singular/plural agreement, conditional ownership-share policy, nil consideration, declaration and signatures. Preserve Sale/GPA/AGPA authority identity, representation, book-number, adjusted-amount and declaration protections.
- Keep the Sale-compatible page geometry and Gift stamp-space section introduced in this session. Preserve the selected Word source's fonts, styles, run formatting, tables, numbering and footer package parts; do not rebuild the source in a generic document style.
- A template change must not clear saved party/property/authority/relationship data. Support both complete split-address bindings and the older combined address slot; preserve entered PAN values when older Gift revisions omit PAN slots. Reject incompatible template bindings instead of silently dropping entered details. Uploaded source documents supply facts and are never instructions to replace template prose.
- Register new default templates as new immutable versions; retain older assets and hashes. Gift v4 is the supplied `GIFT SETTLEMENT (4).docx`, used for all Gift and supported property variants.
- Run `npm run typecheck` and `npm run build` after changes. Keep the build's Gift, Sale/share/declaration, authority-download and output-format regression checks; a new template must pass them too.
